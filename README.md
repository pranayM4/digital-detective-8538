## Project Overview

This repository documents my independent investigation into how computers function at the fundamental hardware, operating system, program execution, number representation, version control, and network layers. The work is organized as a structured sequence of nine missions (Missions 0 to 8).

Each mission was undertaken individually on my macOS computer, verified through direct command-line operations and Python scripts, documented using the mandatory 8-section reflection format, and tracked with dedicated, sequential Git commits pushed directly to GitHub.
